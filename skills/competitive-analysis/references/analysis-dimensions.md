# 竞品对比维度定义

本文档定义竞品分析的四个维度体系，每个维度包含具体检查项和评分标准。

---

## 评分标准

| 分值 | 含义 | 标准 |
|------|------|------|
| 5 | 优秀 | 行业领先，体验/功能突出 |
| 4 | 良好 | 超出平均水平，无明显短板 |
| 3 | 一般 | 达到行业平均水平 |
| 2 | 较弱 | 低于平均水平，有明显不足 |
| 1 | 缺失 | 不支持或完全缺失该能力 |

---

## 一、功能维度

### 1.1 核心功能

检查项：
- 核心业务流程是否完整覆盖
- 关键功能是否满足目标用户需求
- 功能深度是否足够（配置项、自定义能力）
- 数据处理能力（导入/导出/批量操作）

### 1.2 辅助功能

检查项：
- 搜索和筛选能力
- 通知和消息机制
- 权限管理和角色控制
- 数据统计和报表功能
- 第三方集成（开放 API、Webhook）

### 1.3 特色功能

检查项：
- 独有的差异化功能
- 创新性交互方式
- AI 或智能化特性
- 行业特定的增值功能

### 1.4 缺失功能

检查项：
- 目标用户群体期望但未提供的功能
- 竞品普遍具备但该产品缺失的功能
- 功能缺口对用户决策的影响程度

### 功能对比标记

| 标记 | 含义 |
|------|------|
| 支持 | 功能完整可用 |
| 部分支持 | 功能存在但有明显限制 |
| 不支持 | 功能缺失 |
| 未知 | 无法通过公开信息确认 |

---

## 二、体验维度

### 2.1 页面布局

检查项：
- 信息层级是否清晰
- 导航结构是否合理
- 关键操作是否易于发现
- 页面加载后的首屏信息密度

评分要点：5=布局清晰高效，3=基本可用，1=混乱难用

### 2.2 交互流程

检查项：
- 核心任务的完成步骤数
- 操作路径是否符合用户心智模型
- 表单填写和提交流程
- 错误恢复和撤销机制

评分要点：5=极简流畅，3=无明显卡点，1=流程繁琐

### 2.3 响应速度

检查项：
- 页面首次加载时间
- 关键操作响应时间
- 大数据量下的性能表现
- 移动端适配性能

评分要点：5=即时响应，3=可接受延迟，1=明显卡顿

### 2.4 错误处理

检查项：
- 错误提示的清晰度和指引性
- 异常状态的友好展示
- 数据保存和防丢失机制
- 网络异常的容错处理

评分要点：5=优雅处理并引导修复，3=有基本提示，1=无处理或提示不清

### 2.5 新手引导

检查项：
- 首次使用的引导流程
- 帮助文档和工具提示
- 空状态的引导设计
- 学习曲线的平缓程度

评分要点：5=零门槛上手，3=需少量学习，1=学习成本高

## 三、技术维度

### 3.1 技术栈

检查项：
- 前端框架和技术选型
- 后端架构（单体/微服务/Serverless）
- 数据库和存储方案
- 部署方式（云原生/传统部署）

### 3.2 性能指标

检查项：
- 页面加载性能（LCP、FID、CLS 等 Core Web Vitals）
- 并发处理能力
- 数据吞吐量
- 可用性指标（SLA）

### 3.3 API 设计

检查项：
- API 文档完整性
- 接口规范程度（RESTful/GraphQL/RPC）
- 版本管理策略
- 限流和鉴权机制

### 3.4 数据安全

检查项：
- 数据加密（传输和存储）
- 用户隐私保护措施
- 合规认证（等保、GDPR 等）
- 审计日志能力

### 3.5 可扩展性

检查项：
- 插件或扩展机制
- 自定义能力（字段、流程、规则）
- 多租户支持
- 国际化和多语言

---

## 四、商业维度

### 4.1 定价策略

检查项：
- 收费模式（免费/订阅/按量/一次性）
- 定价区间和档位
- 免费版功能限制
- 性价比评估

### 4.2 用户规模

检查项：
- 注册用户数/活跃用户数
- 目标用户群体特征
- 用户增长趋势
- 用户口碑和评价

### 4.3 市场份额

检查项：
- 行业排名和市场地位
- 主要客户案例
- 渠道覆盖能力
- 品牌影响力

### 4.4 盈利模式

检查项：
- 主要收入来源
- 变现能力评估
- 商业化可持续性
- 生态和合作伙伴体系

---

## 维度权重参考

| 维度 | 默认权重 | 适用场景 |
|------|---------|---------|
| 功能维度 | 40% | 产品功能对比为核心目标时 |
| 体验维度 | 25% | 面向 C 端产品或重视用户体验时 |
| 技术维度 | 20% | 技术选型或架构参考为主要目的时 |
| 商业维度 | 15% | 市场定位和竞争策略分析时 |

可根据具体分析目标调整权重分配。
