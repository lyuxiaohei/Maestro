# 竞品分析报告模板

本模板定义竞品分析报告的标准结构。生成报告时按此模板填充内容。

---

## 报告头部

```markdown
# 竞品分析报告

- **分析日期**：{YYYY-MM-DD}
- **分析人**：{分析人姓名}
- **项目名称**：{项目名称}
- **分析范围**：{竞品数量} 个竞品
```

## 截图采集清单

```markdown
## 截图采集清单

以下截图需人工采集，用于补充报告的视觉对比素材。

| 竞品 | 页面/功能 | 采集要点 | 优先级 |
|------|----------|---------|--------|
| {竞品A} | 首页/登录页 | 整体布局、视觉风格 | 高 |
| {竞品A} | 核心功能页 | 功能入口、操作流程 | 高 |
| {竞品A} | 设置/个人中心 | 功能完整度 | 中 |
| {竞品B} | 首页/登录页 | 整体布局、视觉风格 | 高 |
| {竞品B} | 核心功能页 | 功能入口、操作流程 | 高 |
| {竞品C} | ... | ... | ... |

### 采集说明

1. 截图分辨率统一为 {1920×1080}（桌面端）或 {375×812}（移动端）
2. 每个页面截取完整视图，确保关键信息可见
3. 标注截图中的交互元素和关键功能入口
4. 截图命名格式：`{竞品名}-{页面名}-{日期}.png`
```
