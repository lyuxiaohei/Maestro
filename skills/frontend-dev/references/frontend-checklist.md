# 前端联调自检清单

## UI 还原度

- [ ] 页面布局与设计稿一致（间距、对齐、字号）
- [ ] 响应式布局在目标断点表现正确
- [ ] 加载状态、空状态、错误状态均有展示
- [ ] 动画/过渡效果符合设计要求

## 交互功能

- [ ] 表单校验规则完整（必填、格式、长度、范围）
- [ ] 列表操作正确（分页、筛选、排序、搜索）
- [ ] 按钮/链接防重复点击
- [ ] 弹窗/抽屉关闭后状态重置

## API 联调

- [ ] 所有接口请求路径和参数正确
- [ ] 响应数据解析和类型匹配
- [ ] 接口超时和异常有友好提示
- [ ] 并发请求有 loading 防护

## 安全检查

- [ ] 用户输入做 XSS 转义
- [ ] Token 过期自动跳转登录页
- [ ] 敏感信息不写入 localStorage
- [ ] 路由权限控制生效

## 性能检查

- [ ] 页面首屏加载 < 3s（本地环境）
- [ ] 图片使用懒加载或压缩
- [ ] 列表使用虚拟滚动（大数据量场景）
- [ ] 无不必要的重渲染
