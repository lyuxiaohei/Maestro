# 前端开发

## 触发条件

- 用户要求进行前端开发（"开发前端页面"、"写前端代码"）
- 开发任务规划完成后进入前端开发阶段（P15）
- 用户提供开发任务列表并要求指导前端开发
- 用户提到 frontend-dev

## 执行流程

### 步骤 1：路由规划

- 根据 UI 设计稿规划页面路由结构
- 定义路由配置（路径、组件、权限、懒加载）
- 配置路由守卫和重定向规则
- 输出：路由配置代码

### 步骤 2：类型定义

- 根据接口文档定义 TypeScript 类型/接口
- 定义 DTO、VO、枚举类型
- 输出：类型定义文件

### 步骤 3：业务逻辑开发

- 实现页面组件结构和交互逻辑
- 处理表单校验、条件渲染、列表操作
- 输出：页面组件代码

### 步骤 4：API 封装

- 封装后端接口调用（请求/响应处理）
- 统一错误处理和重试机制
- 配置请求拦截器（Token、Loading）
- 输出：API 封装层代码

### 步骤 5：状态管理

- 设计全局/模块状态结构
- 实现状态读写和派生计算
- 处理异步状态（loading、error、data）
- 输出：状态管理代码

### 步骤 6：安全处理

- XSS 防护（输入转义、CSP 策略）
- CSRF Token 处理
- 敏感信息不存储在 localStorage
- 权限控制（路由级 + 按钮级）
- 输出：安全处理代码

### 步骤 7：AI 审核

- 调用 code-review Skill 对前端代码进行 AI 审核
- 根据审核结果修正问题，确认所有 P0/P1 问题已解决
- 输出：审核通过的前端代码

### 步骤 8：联调自测

- 与后端接口逐个联调，验证数据契约
- 检查跨域配置、接口超时、异常状态展示
- 核对 UI 还原度（布局、交互、边界情况）
- 输出：联调记录和自测报告（详见 `references/frontend-checklist.md`）

## 输入输出规范

**输入：**
- 开发任务列表（Phase 14 输出）
- UI 设计规范（Phase 08 输出）
- API 设计文档（Phase 10 输出）

**输出：**
- 前端源代码（路由、组件、API 封装、状态管理）
- 联调记录、AI 审核报告
