# 复核维度与评分标准

本文档定义原型复核的三个维度及其评分标准。

---

## 维度一：功能覆盖度

### 检查项

| 检查项 | 说明 |
|--------|------|
| 功能清单覆盖 | 功能清单中每个条目在原型中有对应体现 |
| 业务流程完整 | 核心业务流程的所有步骤都有对应页面 |
| 异常流程覆盖 | 错误状态、空状态、边界场景有对应设计 |
| 角色场景覆盖 | 不同用户角色的操作路径均有体现 |

### 覆盖状态定义

| 状态 | 定义 |
|------|------|
| 已覆盖 | 功能在原型中有完整页面/组件和交互流程 |
| 部分覆盖 | 功能有体现但缺少部分交互或异常处理 |
| 未覆盖 | 功能在原型中无任何体现 |

### 评分标准

- **5 分**：覆盖率 >= 95%，异常流程和边界场景完整
- **4 分**：覆盖率 >= 85%，核心流程完整，少量异常流程缺失
- **3 分**：覆盖率 >= 70%，核心流程基本完整，部分功能缺失
- **2 分**：覆盖率 >= 50%，核心流程有缺失
- **1 分**：覆盖率 < 50%，大量功能未覆盖

---

## 维度二：交互合理性

### 检查项

| 检查项 | 说明 |
|--------|------|
| 导航逻辑 | 页面跳转路径清晰，无死循环或断路 |
| 表单交互 | 输入校验及时，错误提示明确，成功反馈到位 |
| 操作路径 | 关键操作路径最短，无冗余步骤 |
| 状态流转 | 加载态、空态、错误态、成功态均有处理 |
| 返回与撤销 | 用户可以返回上一步或撤销操作 |
| 信息架构 | 页面层级合理，信息分类清晰 |

### 评分标准

- **5 分**：交互流畅，所有检查项通过，操作路径最优
- **4 分**：交互基本合理，1-2 个小问题
- **3 分**：存在明显的交互问题，但不影响核心流程
- **2 分**：核心流程交互有问题，影响用户操作
- **1 分**：交互逻辑混乱，用户无法完成操作

---

## 维度三：视觉一致性

### 检查项

| 检查项 | 说明 |
|--------|------|
| 颜色体系 | 主色、辅色、状态色全局统一 |
| 字体规范 | 标题/正文/辅助文字字号和字重一致 |
| 间距规范 | 页面内间距、组件间距统一 |
| 按钮样式 | 同类按钮（主按钮、次按钮、危险按钮）全局一致 |
| 图标风格 | 图标风格（线性/面性/双色）统一 |
| 组件复用 | 同类组件在不同页面表现一致 |

### 评分标准

- **5 分**：视觉高度一致，设计规范严格遵循
- **4 分**：基本一致，个别组件存在微小差异
- **3 分**：存在 2-3 处明显不一致
- **2 分**：多处不一致，缺乏统一规范
- **1 分**：视觉风格混乱，每个页面风格不同

---

## 综合评分

复核总分 = 功能覆盖度 x 0.4 + 交互合理性 x 0.35 + 视觉一致性 x 0.25

| 等级 | 分数范围 | 结论 |
|------|---------|------|
| A | >= 4.0 | 通过，可直接进入下一阶段 |
| B | 3.0 - 3.9 | 有条件通过，需修复 P0/P1 后进入下一阶段 |
| C | 2.0 - 2.9 | 不通过，需大改后重新复核 |
| D | < 2.0 | 不通过，需重新设计 |
