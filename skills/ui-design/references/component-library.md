# 组件库定义

本文档定义 UI 组件库中各组件的规范，包括变体、状态、尺寸和交互规则。

---

## 一、按钮（Button）

### 1.1 类型

| 类型 | 用途 | 样式 |
|------|------|------|
| Primary | 主要操作（提交、确认） | 主色填充 + 白色文字 |
| Secondary | 次要操作（取消、返回） | 白色背景 + 主色边框 + 主色文字 |
| Ghost | 轻量操作（筛选、切换） | 透明背景 + 主色文字 |
| Danger | 危险操作（删除、清空） | 红色填充 + 白色文字 |
| Text | 文字链接（查看详情） | 无背景无边框 + 主色文字 |

### 1.2 尺寸

| 尺寸 | 高度 | 内边距 | 字号 |
|------|------|--------|------|
| Small | 28px | 0 12px | 12px |
| Medium | 36px | 0 16px | 14px |
| Large | 44px | 0 24px | 16px |

### 1.3 状态

| 状态 | 样式 |
|------|------|
| Default | 按类型默认样式 |
| Hover | 背景色加深一级 |
| Active | 背景色加深两级 + 内缩 1px |
| Disabled | 透明度 50% + 禁止点击 |
| Loading | 显示 Spinner + 文字变灰 |

## 二、输入框（Input）

### 2.1 类型

| 类型 | 用途 | 特征 |
|------|------|------|
| Text | 单行文本 | 默认输入框 |
| Textarea | 多行文本 | 可拖拽调整高度 |
| Search | 搜索 | 带搜索图标 + 清除按钮 |
| Password | 密码 | 带显示/隐藏切换 |
| Number | 数字 | 带增减按钮 |

### 2.2 尺寸

| 尺寸 | 高度 | 内边距 | 字号 |
|------|------|--------|------|
| Small | 28px | 0 8px | 12px |
| Medium | 36px | 0 12px | 14px |
| Large | 44px | 0 16px | 14px |

### 2.3 状态

| 状态 | 样式 |
|------|------|
| Default | 白色背景 + 中性色边框 |
| Focus | 主色边框 + 浅主色外发光 |
| Error | 红色边框 + 错误提示文字 |
| Disabled | 灰色背景 + 禁止输入 |
| Read-only | 无边框 + 浅灰背景 |

### 2.4 增强元素

- **前缀/后缀**：图标或文字（如货币符号、单位）
- **字数统计**：右下角显示 `已输入/最大字数`
- **清除按钮**：输入内容后右侧显示清除图标

## 三、选择器（Select / Checkbox / Radio / Switch）

### 3.1 下拉选择（Select）

| 属性 | 值 |
|------|-----|
| 高度 | 与 Input 一致 |
| 下拉面板 | 白色背景 + --shadow-lg + 最大高度 300px 滚动 |
| 选项高度 | 36px |
| 选中态 | --color-primary-50 背景 + 主色文字 |
| 多选 | 勾选图标 + 标签化展示 |

### 3.2 复选框（Checkbox）

| 属性 | 值 |
|------|-----|
| 尺寸 | 16px × 16px |
| 选中态 | 主色填充 + 白色勾选 |
| 半选态 | 主色填充 + 横线 |
| 禁用态 | 灰色背景 + 禁止交互 |

### 3.3 开关（Switch）

| 属性 | 值 |
|------|-----|
| 尺寸 | 44px × 22px |
| 开启态 | 主色背景 + 圆点右侧 |
| 关闭态 | 中性色背景 + 圆点左侧 |
| 过渡 | 0.2s ease |

## 四、卡片（Card）

### 4.1 类型

| 类型 | 用途 | 特征 |
|------|------|------|
| Basic | 信息展示 | 标题 + 正文 + 操作区 |
| Media | 图文展示 | 顶部图片 + 底部内容 |
| Statistic | 数据指标 | 大数字 + 标签 + 趋势图标 |
| Action | 操作入口 | 图标 + 标题 + 描述 |

### 4.2 通用规范

| 属性 | 值 |
|------|-----|
| 圆角 | --radius-md (8px) |
| 阴影 | --shadow-sm |
| 内边距 | --spacing-4 (16px) |
| Hover 阴影 | --shadow-md |
| 边框 | 1px solid --color-neutral-200 |

## 五、表格（Table）

### 5.1 结构

| 区域 | 规范 |
|------|------|
| 表头 | --color-neutral-50 背景 + --font-size-body-sm + 600 字重 |
| 表体行高 | 48px（紧凑模式 40px） |
| 行分割线 | 1px solid --color-neutral-100 |
| 斑马纹 | 偶数行 --color-neutral-50 背景 |
| 固定列 | 阴影分隔 + 背景色区分 |

### 5.2 交互

| 操作 | 行为 |
|------|------|
| 行 Hover | --color-neutral-50 背景 |
| 行选中 | --color-primary-50 背景 |
| 排序 | 表头点击 + 升降序图标 |
| 分页 | 底部分页器（每页条数选择 + 页码跳转） |
| 空状态 | 居中图标 + 提示文字 + 操作按钮 |

### 5.3 列宽策略

- 固定列：操作列、状态列、序号列
- 弹性列：名称、描述等文本列按比例分配
- 最小宽度：文字列 120px，操作列 80px

## 六、导航（Navigation）

### 6.1 顶部导航（TopNav）

| 属性 | 值 |
|------|-----|
| 高度 | 56px |
| 背景 | 白色 + 底部 1px 分割线 |
| Logo 区 | 左侧固定，宽度 200px |
| 菜单项 | 文字 + 间距 24px + 下划线选中态 |
| 操作区 | 右侧固定（搜索、通知、用户头像） |

### 6.2 侧边导航（SideNav）

| 属性 | 值 |
|------|-----|
| 宽度 | 220px（折叠 64px） |
| 背景 | --color-neutral-900 或白色 |
| 菜单项高度 | 44px |
| 层级缩进 | 每级 +16px |
| 选中态 | 主色背景（深色模式）或主色左边框 + 浅主色背景 |
| 图标 | 20px + 文字间距 12px |

### 6.3 面包屑（Breadcrumb）

| 属性 | 值 |
|------|-----|
| 字号 | --font-size-caption (12px) |
| 分隔符 | "/" 或右箭头图标 |
| 当前页 | --color-neutral-800 + 不可点击 |
| 上级页 | --color-neutral-400 + Hover 主色 |

## 九、组件命名规范

组件命名遵循以下规则：

- **Token 前缀**：所有 CSS 变量使用 `--ui-` 前缀
- **组件类名**：BEM 命名（`.block__element--modifier`）
- **状态后缀**：`is-{state}`（如 `.btn.is-disabled`、`.input.is-focused`）
- **尺寸后缀**：`-{size}`（如 `.btn-sm`、`.btn-lg`）
