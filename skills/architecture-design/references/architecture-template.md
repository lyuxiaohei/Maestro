# 架构设计文档模板

本模板定义架构设计文档的标准结构。生成架构文档时按此模板填充内容。

---

## 文档头部

```markdown
# 架构设计文档

- **文档版本**：{v1.0}
- **创建日期**：{YYYY-MM-DD}
- **设计人**：{设计人姓名}
- **项目名称**：{项目名称}
- **上游文档**：方案设计文档（Phase 09）v{版本号}
```

---
