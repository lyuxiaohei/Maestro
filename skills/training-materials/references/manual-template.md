# 操作手册模板

## 文档结构

```markdown
# [系统名称] 操作手册

## 1. 系统概述
- 系统简介
- 适用角色
- 访问方式

## 2. 功能模块操作

### 2.1 [模块名称]

#### 操作一：[操作名称]
- **目的：** 完成什么目标
- **前置条件：** 需要什么权限/数据准备
- **操作步骤：**
  1. 步骤一
  2. 步骤二
  3. ...
- **预期结果：** 操作成功后的效果
- **注意事项：** 常见问题和注意事项
```

## FAQ 格式

```markdown
## FAQ

### [模块名称]

**Q: 问题描述？**
A: 解答内容

**Q: 问题描述？**
A: 解答内容
```

## PPT 大纲格式

```markdown
## 幻灯片 1：标题
- 主标题
- 副标题
- 讲师/日期

## 幻灯片 2：目录
- 培训内容概览

## 幻灯片 N：[功能模块]
- 要点一
- 要点二
- 备注：讲师补充说明
```
