# 测试用例模板

## 用例格式

```markdown
| 用例编号 | 模块 | 用例标题 | 前置条件 | 操作步骤 | 预期结果 | 优先级 | 状态 |
|---------|------|---------|---------|---------|---------|--------|------|
| TC-001  |      |         |         |         |         | P0     | 待执行 |
```

## 优先级定义

- **P0** — 核心功能链路，阻塞性用例
- **P1** — 重要功能，影响主流程
- **P2** — 一般功能，不影响主流程
- **P3** — 边界场景和体验细节
