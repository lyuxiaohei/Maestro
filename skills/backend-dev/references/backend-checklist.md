# 后端开发自检清单

## 代码规范

- [ ] 类名/方法名/变量名遵循项目命名规范
- [ ] 公共方法有 JSDoc/Javadoc 注释
- [ ] 日志使用统一 Logger，级别正确（DEBUG/INFO/WARN/ERROR）
- [ ] 魔法值提取为常量或枚举

## 安全检查

- [ ] SQL 使用参数化查询，无字符串拼接
- [ ] 接口有权限校验（认证 + 鉴权）
- [ ] 敏感数据脱敏（手机号、身份证、密码）
- [ ] 输入参数校验完整（类型、范围、长度）
- [ ] 文件上传有类型和大小限制

## 性能检查

- [ ] 无 N+1 查询，批量操作使用 IN 查询或 JOIN
- [ ] 热点数据使用缓存，缓存 key 有过期策略
- [ ] 大列表查询有分页，避免全表扫描
- [ ] 数据库连接、文件句柄等资源及时释放

## 异常处理

- [ ] 业务异常使用自定义异常类，携带错误码
- [ ] 全局异常拦截器覆盖所有异常类型
- [ ] 异常日志包含上下文信息（请求参数、用户 ID）
- [ ] 不吞异常（空 catch 块）

## 事务管理

- [ ] 写操作在事务内执行
- [ ] 事务粒度合理，不在事务内做 RPC/HTTP 调用
- [ ] 只读操作标记 @Transactional(readOnly=true)
