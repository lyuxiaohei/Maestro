# 后端开发

## 触发条件

- 用户要求进行后端开发（"开发后端接口"、"写后端代码"）
- 开发任务规划完成后进入后端开发阶段（P15）
- 用户提供开发任务列表并要求指导后端开发
- 用户提到 backend-dev

## 执行流程

### 步骤 1：接口层开发

- 根据 API 设计文档实现 Controller/路由层
- 定义请求/响应 DTO，校验参数注解
- 配置路由规则和中间件挂载
- 输出：接口层代码

### 步骤 2：服务层开发

- 实现核心业务逻辑，处理业务规则校验
- 编排领域服务调用，管理事务边界
- 输出：服务层代码

### 步骤 3：持久层开发

- 实现数据访问逻辑（Repository/Mapper）
- 编写 SQL 映射和查询构建
- 处理数据转换和批量操作
- 输出：持久层代码

### 步骤 4：中间件集成

- 集成缓存（Redis）、消息队列、定时任务等中间件
- 配置连接池、序列化、重试策略
- 输出：中间件集成代码

### 步骤 5：异常处理

- 实现统一异常处理和错误码体系
- 处理业务异常、参数校验异常、系统异常
- 配置全局异常拦截器
- 输出：异常处理代码

### 步骤 6：代码自检

- 检查代码规范：命名、注释、日志级别
- 检查安全项：SQL 注入、权限控制、敏感数据处理
- 检查性能项：N+1 查询、缓存使用、连接释放
- 输出：自检清单（详见 `references/backend-checklist.md`）

### 步骤 7：AI 审核

- 调用 code-review Skill 对后端代码进行 AI 审核
- 根据审核结果修正问题，确认所有 P0/P1 问题已解决
- 输出：审核通过的后端代码

## 输入输出规范

**输入：**
- 开发任务列表（Phase 14 输出）
- 详细设计文档（Phase 13 输出）
- API 设计文档（Phase 10 输出）

**输出：**
- 后端源代码（接口层、服务层、持久层、中间件、异常处理）
- 自检清单、AI 审核报告
