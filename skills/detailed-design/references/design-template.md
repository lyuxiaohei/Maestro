# 详细设计文档模板

本模板定义详细设计文档的标准结构。生成详细设计文档时按此模板填充内容。

---

## 文档头部

```markdown
# 详细设计文档

- **文档版本**：{v1.0}
- **创建日期**：{YYYY-MM-DD}
- **设计人**：{设计人姓名}
- **项目名称**：{项目名称}
- **上游文档**：最终架构文档（Phase 12）v{版本号}
```
