# 功能用例到组件映射规则

定义如何将功能用例表中的每一行映射到具体的UI组件实例。

---

## 映射原则

**一用例一组件**：每个功能用例对应至少一个UI组件实例。

---

## 映射流程

### Step 1: 操作列关键词提取

```
用例操作 → 分词 → 提取动词 + 名词 → 查询映射矩阵
```

### Step 2: 预期结果列元素识别

```
用例预期结果 → 识别UI元素关键词 → 查询映射矩阵
```

### Step 3: 组件配置生成

```
映射结果 → 提取具体参数 → 生成组件配置JSON
```

## 映射示例

### 示例用例1

```markdown
| 1 | 选择类型 | 点击"仅退款"或"退货退款" Tab | 选中项橙色背景白字 `[草案]` |
```

**映射分析：**
- 操作：点击 Tab → `Tab` 组件
- 预期结果：选中项橙色背景白字 → 选中样式配置

**映射输出：**
```json
{
  "component_type": "Tab",
  "component_name": "申请类型Tab",
  "config": {
    "items": ["仅退款", "退货退款"],
    "selected_style": {
      "background": "linear-gradient(#ff6034, #ee0a24)",
      "color": "#fff"
    },
    "default_selected": 0
  }
}
```

### 示例用例2

```markdown
| 3 | 上传凭证 | 点击"添加图片"按钮 | 打开图片选择器，最多3张，显示缩略图预览 `[草案]` |
```

**映射分析：**
- 操作：点击添加图片按钮 → `Upload` 组件
- 预期结果：最多3张、缩略图预览 → Upload配置

**映射输出：**
```json
{
  "component_type": "Upload",
  "component_name": "凭证上传",
  "config": {
    "max_count": 3,
    "accept": "image/*",
    "show_preview": true,
    "preview_size": "thumbnail"
  }
}
```

### 示例用例3

```markdown
| 6 | 提交申请 | 点击"提交申请"按钮 | 弹出确认弹窗，点击"确认"跳转进度页 `[草案]` |
```

**映射分析：**
- 操作：点击提交按钮 → `Button` 组件 + `ConfirmModal` 组件
- 预期结果：弹出确认弹窗、跳转 → 二次确认逻辑

**映射输出：**
```json
[
  {
    "component_type": "Button",
    "component_name": "提交申请按钮",
    "config": {
      "text": "提交申请",
      "type": "primary",
      "onclick": "triggerModal('confirm')"
    }
  },
  {
    "component_type": "ConfirmModal",
    "component_name": "提交确认弹窗",
    "config": {
      "title": "确认提交",
      "content": "确认提交售后申请？",
      "confirm_text": "确认",
      "onconfirm": "location.href='aftersales_progress.html'"
    }
  }
]
```

## 预期结果样式映射

| 预期结果关键词 | 样式配置 |
|----------------|----------|
| 橙色、橙色背景、橙色渐变 | `background: linear-gradient(#ff6034, #ee0a24)` |
| 红色、红色背景、红色样式 | `background: #ee0a24; color: #fff` |
| 绿色、绿色背景、绿色标签 | `background: #52c41a; color: #fff` |
| 灰色、灰色背景、置灰 | `background: #f5f5f5; color: #999` |
| 蓝色、蓝色背景、蓝色标签 | `background: #2196f3; color: #fff` |
| 高亮、选中高亮 | `background: #e6f7ff; color: #1890ff` |
| 置灰、禁用、按钮置灰 | `disabled: true; opacity: 0.5` |
| 半透明、图片半透明 | `opacity: 0.5` |

## 状态标记处理

| 状态标记 | 映射处理 |
|----------|----------|
| `[草案]` | 正常映射，标记来源为草案 |
| `[待原型]` | 映射后附加"待验证"注释 |
| `[待确认]` | 映射后附加确认提示占位符 |

---

## 用例未映射处理

| 未映射情况 | 处理方式 |
|------------|----------|
| 操作关键词未匹配 | 使用基础 `Button` 组件，提示补充 |
| 预期结果未匹配 | 使用默认样式，提示补充 |
| 复合用例（多个操作） | 拆分为多个组件，顺序绑定事件 |
