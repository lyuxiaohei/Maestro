# 会议纪要

## 触发条件

- 用户要求整理会议内容（"帮我整理会议记录"、"生成会议纪要"）
- 用户提供会议转写文本或手动记录并要求生成纪要
- P01 需求调研阶段的访谈记录整理
- P03 正式会议纪要生成
- 用户提到 meeting-minutes

## 跨阶段复用说明

本 Skill 同时服务两个阶段：
- **P01（需求调研）**：访谈记录整理，输出访谈纪要
- **P03（会议纪要）**：正式会议纪要生成，输出完整纪要文档

P01 模式侧重需求采集，自动标注需求条目和优先级线索。
P03 模式侧重决议跟踪，自动生成分派行动项和待办汇总。

根据输入内容自动识别模式，也可通过用户指令显式指定。

## 执行流程

### 步骤 1：会议信息提取

- 从输入内容中提取会议基础信息
- 识别：会议日期、时间、地点、参与人员、会议主题
- 标注信息来源（转写文本/手动记录/口述）
- 缺失信息处标记 `[待补充]`
- 输出：会议基础信息表

### 步骤 2：议题归纳整理

- 识别并归纳会议讨论的主要议题
- 按议题分组讨论内容，去除重复和偏题内容
- 每个议题提炼核心讨论要点（3-5 条）
- 标注议题间的关联关系
- 输出：议题列表与讨论要点

### 步骤 3：决议与行动项识别

- 从讨论内容中识别已达成的决议（明确结论）
- 区分"已决议"、"待确认"、"下次讨论"
- 提取行动项：具体任务、隐含任务、后续跟进
- 标注每个决议的支持依据和参与决策人
- 输出：决议清单与初步行动项

### 步骤 4：会议纪要文档生成

- 按模板生成结构化会议纪要（详见 `references/minutes-template.md`）
- 填充头部信息、议题列表、决议内容、行动项
- 确保格式统一，语言简洁专业
- 输出：会议纪要 Markdown 文档

### 步骤 5：行动项分派

- 为每个行动项指定负责人（从参与者中匹配或标记 `[待指派]`）
- 设定建议截止日期（根据紧急程度推断或标记 `[待确定]`）
- 按格式规范输出行动项表格（详见 `references/action-item-format.md`）
- 输出：行动项分派表

### 步骤 6：待办事项汇总

- 汇总所有行动项为待办清单
- 按优先级排序（紧急 > 重要 > 常规）
- 标注与上次纪要待办的关联（如有上下文）
- 输出：待办事项汇总表

### 步骤 7：纪要分发与确认

- 生成纪要确认清单（需确认人、确认项）
- 标注纪要版本号和生成时间
- 输出待分发的纪要终稿
- 输出：纪要终稿 + 确认清单

## 输入输出规范

**输入：**
- 会议内容（音频转写文本 / 手动记录 / 用户口述）
- 会议类型标识（可选：P01 访谈 / P03 正式会议）
- 参与者信息（可选）
- 上次会议纪要（可选，用于待办关联）

**输出：**
- 结构化会议纪要（Markdown 格式）
- 行动项分派表
- 待办事项汇总表
- 纪要确认清单
