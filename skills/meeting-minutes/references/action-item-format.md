# Action Item Format: 行动项格式规范

本文档定义会议纪要中行动项的标准格式、字段含义和填写规范。

---

## 行动项字段定义

| 字段 | 必填 | 说明 | 示例 |
|------|------|------|------|
| 编号 | 是 | 唯一标识，格式 `A-{NNN}` | A-001 |
| 内容 | 是 | 任务描述，动词开头，具体可执行 | 完成竞品分析报告初稿 |
| 负责人 | 是 | 任务执行人，无法确定时填 `[待指派]` | 张三 |
| 截止日期 | 是 | 预期完成日期，格式 YYYY-MM-DD | 2026-06-01 |
| 优先级 | 是 | 紧急 / 重要 / 常规，三选一 | 紧急 |
| 状态 | 是 | 当前执行状态，见状态枚举 | 待启动 |

---

## 优先级定义

| 级别 | 含义 | 处理建议 |
|------|------|---------|
| 紧急 | 阻塞其他工作或存在时效约束 | 24 小时内启动，优先处理 |
| 重要 | 对项目目标有显著影响 | 3 个工作日内启动 |
| 常规 | 正常推进事项 | 按排期正常推进 |

---

## 状态枚举

| 状态 | 含义 | 可转换到 |
|------|------|---------|
| 待启动 | 尚未开始执行 | 进行中、已取消 |
| 进行中 | 正在执行中 | 已完成、已阻塞 |
| 已完成 | 执行完毕并确认 | — |
| 已阻塞 | 因外部依赖无法推进 | 进行中、已取消 |
| 已取消 | 不再需要执行 | — |

---

## 填写规范

### 内容描述

- 使用动词开头：完成、编写、确认、评审、更新、提交、协调
- 描述具体可交付成果，避免模糊表述
- 一项一个任务，不合并多个独立任务

**示例：**
- 正确：`完成竞品分析报告初稿，覆盖 3 个核心竞品`
- 错误：`做一些分析工作`

### 负责人

- 填写具体姓名，不使用"大家"、"相关人员"
- 多人负责时标注主负责人（在前），协作人在括号内注明
- 示例：`张三（主）、李四（协）`
- 无法确定时填 `[待指派]`，需在下次会议确认

### 截止日期

- 格式：`YYYY-MM-DD`
- 从会议讨论内容中推断（"下周三前"、"月底之前"）
- 无明确时限时根据优先级设定建议日期：
  - 紧急：会议日期 +2 天
  - 重要：会议日期 +5 天
  - 常规：会议日期 +10 天
- 无法推断时填 `[待确定]`

## 行动项表格示例

```markdown
| 编号 | 内容 | 负责人 | 截止日期 | 优先级 | 状态 |
|------|------|--------|---------|--------|------|
| A-001 | 完成用户访谈记录整理 | 王五 | 2026-06-01 | 重要 | 待启动 |
| A-002 | 提交需求分类初稿 | 李四 | 2026-05-28 | 紧急 | 进行中 |
| A-003 | 确认技术方案选型 | 张三（主）、赵六（协） | 2026-06-05 | 重要 | 待启动 |
| A-004 | 更新项目排期表 | [待指派] | [待确定] | 常规 | 待启动 |
```

---

## 编号规则

- 格式：`A-{NNN}`，NNN 为三位数字
- 同一份纪要内从 A-001 起顺序编号
- 关联上次纪要行动项时，在内容中注明来源：`（续 A-012，上次纪要）`
- 取消的行动项保留编号并标记状态为"已取消"，不删除行
