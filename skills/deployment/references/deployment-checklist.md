# 上线检查清单

## 代码检查

- [ ] 所有 P0/P1 缺陷已修复并验证
- [ ] 代码已合并到发布分支
- [ ] 版本号已更新
- [ ] CHANGELOG 已更新

## 环境检查

- [ ] 生产环境配置已准备（服务器、数据库、中间件）
- [ ] 环境变量已配置
- [ ] 域名和 SSL 证书已配置
- [ ] 数据库迁移脚本已准备并在预发环境验证

## 安全检查

- [ ] 生产密钥和凭据已配置（不使用开发环境凭据）
- [ ] 日志不输出敏感信息
- [ ] 接口鉴权已开启
- [ ] CORS 配置正确

## 监控检查

- [ ] 应用监控已配置（错误率、响应时间）
- [ ] 告警规则已设置
- [ ] 日志采集正常
- [ ] 关键业务指标可观测

## 回滚准备

- [ ] 回滚方案已制定
- [ ] 数据库回滚脚本已准备
- [ ] 上一版本可快速恢复
- [ ] 回滚决策人和触发条件已明确

## 灰度发布记录格式

```markdown
| 时间 | 灰度范围 | 用户比例 | 错误率 | 平均响应时间 | 状态 |
|------|---------|---------|--------|------------|------|
| HH:MM | 地区/功能 | X% | X% | Xms | 进行中/通过/回滚 |
```
